# 🍝 Recipe Card

A simple and responsive recipe card webpage built using HTML5 and CSS3.

## 📌 Project Overview

This project displays a recipe in a clean card layout with:

- Recipe image
- Ingredients list
- Numbered preparation steps
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Clean and attractive recipe card design
- Semantic HTML structure
- Ingredients displayed using an unordered list
- Preparation steps displayed using an ordered list
- Recipe image with figure and figcaption
- Responsive layout
- Mobile-friendly design
